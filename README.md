# 무엇이 여행을 여행으로 만드는가

분실에서 회수까지 이어지는 사건을 세 가지 방식으로 경험하는 인터랙티브 포스터.

- **자료**: 원본 사진과 단계 해설, 세 지표의 평가를 읽습니다.
- **감정**: 검은 콜라주와 원본 파노라마의 감정어를 따라갑니다.
- **몰입**: 사건 안에서 스크롤, 클릭, 터치로 여정을 경험합니다.

첫 화면을 클릭하면 모드 소개가 나타납니다. 모드를 선택하면 여정으로 들어갑니다.
노트북과 휴대폰의 화면 비율에 맞춰 구성이 바뀝니다.
소리는 몰입 모드에서 직접 켤 수 있습니다. 기기의 동작 줄이기 설정을 반영합니다.

GitHub Pages: main 브랜치의 루트 폴더를 게시합니다. 별도 빌드나 서버는 필요하지 않습니다.
